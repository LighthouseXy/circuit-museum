# 产品编年史 · 品类发展图录

2026-10-03 · 新首版设计。此文取代 first-edition-design.md 中的首页、时间线与视觉方案。此前40件版的验收不覆盖本次改版。

## 核心决定与馆藏

正式功能名称固定为“产品编年史”。必须分别讲述手机、电脑、手表、手环、耳机五条发展脉络，而不是将全部馆藏排序后改名。每条说明：从什么用途/形态开始、哪些变化改变了使用、当代代表保留或改变了什么。

总馆藏保持40件，固定名单见 `chronicles-collection-40.csv`；保留TPS-L2、2006年初代MacBook和iPhone 4。`chronicles-manifest.json`明确10件替换关系。编年史节点是对馆藏的引用，不增加馆藏计数；背景、原型、技术事件、与品类有关的配套设备不伪装成独立馆藏。既有主分类与五条编年史是不同维度：例如耳机属于声音，手表/手环属于穿戴；不能通过旧分类名称自动生成脉络。

旧详情如果移出首版，生成器应清理旧产物或返回明确的历史地址说明，不能残留成50件隐形馆藏。无须删除历史研究资料或原图文件。替换产品的相关链接、搜索计数、年代范围和分类数量随最终collection.json重算。

## 页面与阅读顺序

- `/`：直接进入产品史图录，默认手机。不是宣传着陆页。顶部为简洁文字馆名、导航“产品编年史 / 馆藏 / 关于”；标题“产品编年史”及一行说明后，立即出现五类入口和当前品类内容。
- `/chronicles/?type=phones`：同一图录的可分享地址；另外四值为computers、watches、bands、headphones。首页可指向该地址，或复用同一内容。每类均有可直接访问的URL，刷新、前进后退保留所选品类。
- `/timeline/`：保留旧链接兼容，转到产品编年史；不再展示全产品混排的旧时间轴。
- `/exhibits/`：40件的查找目录。保留搜索、主类型、年代筛选；以横向展签行替代连续三列门户卡片。手机一列、图片在名称附近，保持此前首屏可见展品的修复。
- `/exhibits/[slug]/`：实物详情；增加“在××编年史中查看”入口，跳回对应节点。原中文正文、事实、许可、视频、内部观察继续有效。

每类开头有短题目、60—90字发展概述，以及2个“发生了什么变化”的短提示。紧接一件有照片的关键展品作为起读点（手机iPhone 4、电脑MacBook 2006、手表初代Apple Watch、手环Flex、耳机SP/3优先；未有授权照片时，可将起读展品改为同类另一件已有授权照片的馆藏，并同时修改featuredSlug和名称；也可保留当前展品的真实文字展签，不借错型号）。提供“从起点读起”页内链接，下面仍严格按时间升序呈现完整脉络；起读点引用同一展品，不重复计数或伪造第二节点。

## 独立视觉结构

方向是翻阅产品史图录，画面由产品及变化说明构成。取消旧首页的左右营销首屏、两行口号、双CTA、数字统计带、圆形带点标记和连续三列栏目；不使用AI Device Evolution组件、配色令牌或设计稿作为新模板。

背景纯白 `#FFFFFF`，正文近黑 `#202020`，辅助灰 `#656565`，分隔线 `#D8D8D8`，链接用低饱和蓝 `#264E73`。颜色只是辅助，区别主要来自叙事与排版。无需外部字体；系统无衬线正文，年份可等宽。页面不堆英文眉题，中文产品名优先；不做装饰刻度、背景纹理、霓虹或动效转场。

桌面最大阅读区1120px，左右留白32px。标题28—34px；节点产品名24—28px；正文16—18px、行高1.75；来源/日期说明14px。五品类采用可换行的文字导航，有明确当前状态；不要卡片化成另一排指标。桌面可保持品类导航在上方，滚动后仍可访问。

时间轴每个展品用一条开放的图文横行：左侧约90px年份，中间约340px实物照片，右侧产品名、60—100字简介、独立一行“变化：……”、年份口径与来源、详情链接。图片contain，保持物体轮廓，不裁掉端口/屏幕。行间以留白为主，只用浅线连接年代。背景节点用较小的文字段嵌在同一顺序中，明确标“历史背景 / 原型 / 发布事件”，不画成缺照片的产品卡。

手机保持单列：年份和类型标识→产品名→图片→简介和变化→来源/详情。五类入口全部在390px首屏可见，可两行排列或原生select，但不能藏在只能横拖且无提示的区域。标题区不超过约150px；首个起读产品名称及至少部分实物/资料展签在390×844首屏中出现。不得靠缩小正文到12px实现。

## 结构化数据契约

最终 `chronicles.json`：`schemaVersion, title, status, checkedThrough, collectionFile, categories, sources`。`status=ready` 才表示事实与引用可交付；名单manifest不替代完成状态。

Category：`id, label, title, introduction, changes[2], featuredSlug, startYear, endYear, nodes[]`。

Node：`id`全局唯一；`year`整数排序；`dateLabel`给访客的年份口径；`dateKind`从commission/prototype/announcement/approval/launch/manufacture/observed选择；`kind`为exhibit/background；`title, summary, change`为原创中文；`sourceIds[]`至少一项；`exhibitSlug`仅展品节点填写；背景可有`relatedExhibitSlugs[]`。`isContemporary`仅用于该类已核实当代代表，不能自动称“全球最新”。

Source：`id, title, publisher, url, supports, checkedOn`；逐节点渲染紧邻来源。一个来源可支持多节点，但必须保留不同日期含义。1973手持电话演示、1983监管批准，1970Pulsar原型、1972上市，2016AirPods发布和实际开售不能混写。1810腕表订购属于机械前史，不宣称电子表1810问世。

`collection.json`继续为40件详情的唯一正式内容源；新增展品至少含summary/context/design/significance/dateLabel/facts/sourceIds/relatedSlugs。背景节点不需要40件范围外的伪详情页。跨类引用只使用同一slug，不复制产品。图片仍按`media-register.json`/实际下载证据判断授权，不自动使用品牌宣传图。

## 必须验收

1. 页面与导航使用准确名称“产品编年史”；五类都有独立介绍、早期背景、关键变化、当代代表，至少4个有来源节点；绝非对现有40件简单排序。
2. 五类均有不少于2个真实展品节点，详情可直达，返回保留品类和节点定位；所有节点来源、年份口径可见。原型与产品区分，未来计划不写成已上市。
3. 全站唯一馆藏40件，必留3件存在；编年史背景与重复引用不改变计数；没有移出展品的悬空关联。
4. 首屏/整页与旧站实际截图对照：没有旧营销骨架、圆点环标志、数量带或连续三列门户模块。用真实产品和独立品类叙事建立区别，不接受仅换色的交付。
5. 390×844五类可达，起读产品可见；320px无横向溢出；键盘、焦点、URL恢复和来源链接可用。图片缺失有明确说明，已配置图片必须解码成功。
6. 至今指核查截止2026-10-03的已核实代表；不强求每年一件、不以未经证实的“世界第一”补齐起点。每类末尾标核查日期及“精选节点，非完整年表”。
7. 原5个视频和3处内部观察按仍在馆藏的slug保留；图片署名与许可不因改版丢失。最终报告重算实际照片数量，不沿用旧27件数字。
