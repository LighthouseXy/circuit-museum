# 实现说明

更新于2026-10-04。

## 页面与状态

采用Node.js内建模块生成静态HTML，原生CSS与JavaScript处理交互，没有生产依赖或外部运行时API。40个详情页的正文、图片署名和史料直接存在于HTML中。每件按代表性、背景、设计、实际使用与局限组织五节长文，原生页内目录通过锚点跳转，各节显示对应引用；2026年产品使用「当代观察」标签。

导航顺序为：首页 `/` → 馆藏 `/exhibits/` → 产品编年史 `/chronicles/` → 关于 `/about/`。首页独立介绍电子产品设计、技术与生活史线上博物馆，以TPS-L2、2006年第一代MacBook和iPhone 4作为起读精选；提供馆藏主入口、实际产品类型链接及五类编年史入口。

`/chronicles/` 独立阅读产品编年史。五类导言与年代序列共用正式 `docs/chronicles.json`，20个真实馆藏节点的摘要与对应展品同步，背景节点不生成虚构产品详情。选择类型写入URL；详情链接携带类型和节点，返回时恢复阅读位置。无JavaScript时五类正文仍完整可读。旧 `/timeline/` 由预览服务重定向，并保留静态跳转页。

馆藏为开放展签行。关键词、类型和年代组合筛选，排序及筛选条件写入URL；品牌中文别名集中在 `src/catalog.js`，新增产品不必重复维护品牌翻译。可选会话存储恢复馆藏浏览位置，失败不阻断浏览。

每次构建清理生成目录后重建，防止已撤下产品的详情文件残留。实际详情目录与正式40件馆藏相等；未知与撤展地址均返回404。

## 视觉与媒体

编年史视图按 `docs/chronicles-design.md` 组织页面与CSS：白底、黑字、蓝色文本链接、品类导航、实物起读、年代/照片/正文的开放行。编年史手机首屏先显示起读名称和照片，再给摘要及详情入口；正文保持至少16px。2026-10-04的用户请求将首页独立出来，沿用同一图录风格，用简短说明、开放展品行和文字链接组织内容。旧营销首屏和三列卡片结构已移除，此前来源自查及截图对照见 `implementation-provenance.md`。

33张主照片和HP-35内部图来自逐文件核对的开放许可来源。`src/image-overrides.json` 为实际署名、许可、型号与文件路径；`docs/evidence/image-metadata/` 记录原文件、尺寸和转换。照片等比例缩小、WebP转码，并逐张视觉复核，未使用AI补图。7件缺图显示资料展签；请求失败仍显示名称和来源。

内部观察沿用策展数据的可选 `teardown` 字段，HP-35显示许可内部图；iPhone 4与Steam Deck LCD使用中文简述及拆解外链。5个视频只链接原发布页，无下载、嵌入或自动播放。

## 工作与验证边界

实际遵循ponytail技能，保持平台内建能力。未找到frontend-design/web-design技能，未声称调用。两个子代理分别负责媒体/当代来源核对及测试/搜索审查；功能拓展聊天负责正式策展数据与视觉复核。

Playwright和Sharp使用应用运行环境，仅用于验证与图片维护，不是站点运行依赖。未改动相邻项目，未部署，未配置付费服务或修改全局设置。

逐件内容与来源范围记录在 `evidence/description-content-review.json`，区分正文、原机构索引及原手册转录镜像；当代型号依据官网正文和条件说明。厂商宣称、单件样机体验和策展解读各保留自己的范围，没有推导为群体口碑或长期表现。

2026-10-04的构建、7个文件的语法检查、8项单元测试和20项本地浏览器检查通过，覆盖独立首页、四项导航顺序、馆藏主入口及40件长文与页内目录。2026-10-03的无脚本导航、⌘点击与当代来源专项核查保留为补充证据，本次未重跑这些专项。范围、实际统计和限制见 `test-results.md`。第三方视频播放、其他浏览器、实体手机、完整屏幕阅读器和原生缩放尚未专项验证。
