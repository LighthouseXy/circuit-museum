# 首页与阶段编年史页面方案

2026-10-11。状态：可实施的内容与布局方案，尚未导入正式网站。正式仍为40件、五条编年史；本方案使用这40件与首批ready六件，不使用其余45件候选填充页面。新增文字、阶段与独立预览均在本目录。

## 页面要解决什么

访客先认出一种熟悉的产品，再理解它为何改变。首页提供简短、有真实产品照片的品类发展入口；编年史讲阶段和转折；馆藏用于查型号与读完整介绍。首页和编年史保持两个独立页面。

全站导航依次为**首页 → 产品编年史 → 馆藏 → 关于**，品牌链接返回首页。导航使用文字与当前项标记，不增加品牌圆点图标、搜索浮层或营销按钮组。原有馆藏筛选、详情正文、照片署名和影像出处继续使用。

## 品类为何这样组织

以资料能解释的产品任务划线，不以现有数据库标签直接排列首页。此批形成七条阅读线：首页的声音入口包含播放设备与耳机两线，其他入口各对应一线。数量来自内容，不设长期固定配额。

| 首页入口 | 编年史线 | 节点范围与明确限制 | 入口实物照片 |
| --- | --- | --- | --- |
| 手机 | `phones` | 1973手持原型—2026样本；不覆盖全部移动通信前史、品牌或制式 | iPhone 4 |
| 个人电脑 | `computers` | 1946机构计算背景—2026便携样本；机构设备不称个人电脑起点 | 原消费级MacBook第一代（2006） |
| 声音播放与耳机 | `players`、`headphones` | 播放线1924—2001；耳机线1879背景—2026；各有独立边界 | Walkman TPS-L2 |
| 游戏机 | `gaming` | 1972—2022八件精选；暂不展示2026节点 | Game Boy DMG-01 |
| 电子手表 | `watches` | 1969—2026电子节点；1810订单单独标机械形式前史 | Apple Watch第一代 |
| 活动手环 | `bands` | 2011发布背景—2026列售观察；2014—2026间缺连续样本 | Fitbit Flex |

影像目前只有QV-10，学习有Speak & Spell和Raspberry Pi，阅读与随身资料有PalmPilot、Kindle、iPad；它们用产品专题呈现。HP-35与MX Master 3进入计算/输入专题。专题不冒充品类的完整起源与发展线，也不因没有照片消失。

## 首页：首屏和区块顺序

内容权威文件为[page-content.json](page-content.json)。标题、入口顺序、段落、照片型号、阶段引用和专题都已填写；实现无需再自行选择代表产品。

1. **导航**：四项上述顺序，跳到正文链接可键盘使用。
2. **短导言**：标题“电子产品怎样改变日常生活”；一段定位和一句阅读说明。右侧或段尾一个普通文字链接“在馆藏查找型号”，无双主按钮、统计带或大背景图。
3. **“从熟悉的产品读起”**：六条开放的品类阅读行，依序手机、电脑、声音、游戏、手表、手环。每行包含品类名称、一个具体问题、真实产品照片、两句以内说明、可点击的阶段名称、带年份的代表型号、完整阅读线入口及范围说明。
4. **“沿一件产品继续看”**：四个产品专题，每项一张已有照片、任务说明和全部对应型号链接。两列开放行用于桌面，手机纵向排列。没有大型卡片套卡片，也不复用三列门户首页骨架。
5. **页尾**：策展范围、资料核查与署名入口。实际数量从数据计算；方案预览的“46件计划池”不移植为已完成入馆声明。

六个阅读行不是标签按钮：手机行用“Nokia按键短信—iPhone屏幕界面”讲动作；电脑行用“自己参与组装—书桌系统—携带—维护”讲安排；声音行明确“播放器决定带什么、耳机决定怎么听”。阶段链接落到编年史相应段落，型号链接落到完整展品详情。

### 首页尺寸与阅读节奏

- 页面白底`#fff`，主文字`#202020`，次文字`#656565`，分隔线`#d8d8d8`，文字链接`#264e73`；系统字体。既有通用导航/照片组件可复用，但按下述内容顺序组织。
- 内容最大宽度1120px。1440px时左右居中；≥960px阅读行用约36%照片与64%文字，不另设营销首屏左右分栏。照片与文字都属于同一品类条目。
- 768—959px仍可双栏，照片最小260px；更窄改为单栏。手机侧距18px，320px侧距16px。主体16—18px、行距约1.75，范围/署名不小于14px。
- 手机每行依次为品类/问题、照片与署名、说明、阶段链接、代表型号、范围与阅读全文。照片使用`object-fit:contain`，不裁掉端口、屏幕或实体按键。
- 390×844首屏应看到导航、短导言、馆藏入口、第一条手机问题以及至少32px高的实物照片。导言不用为容纳全部入口压缩成小字。320px也应出现第一条产品入口和照片或明确文字回退。
- 品类之间用留白与细线。阶段名称允许换行；不作必须左右拖动的胶囊栏。表格只用于文档，手机产品页面不用横向表格。

## 产品编年史：先读阶段，再看节点

内容权威文件为[stage-chronicles.json](stage-chronicles.json)：七线、26阶段、47节点，其中9个历史背景、38个不重复展品。保留正式29节点的ID，追加四个ready提议，并加入C64、五个播放节点和八个游戏节点。

每条阅读线的呈现顺序：

1. 页面标题与一句解释；七条品类文字入口，当前项明确。未提供`type`时默认手机。
2. 所选品类标题、一段介绍与范围说明。信息要短，不展开整页内容。
3. **起读产品**：已有照片、准确型号、事件日期，提供“读这件产品的完整介绍”和“从第一阶段读起”。默认分别为iPhone 4、MacBook 2006、TPS-L2、AirPods第一代、Game Boy、Apple Watch第一代、Flex；来源及照片署名可见。
4. **阶段定位**：仅列该线阶段。桌面在时间线左侧约200px处保持可见；手机用原生`details`摘要“本线阶段”，展开纵向链接，初始关闭。正文顶部也有“从第一阶段读起”，定位不依赖脚本。
5. **阶段正文**：标题、选点年份范围、阶段介绍，随后“此时的需要”和“产品的转折”。这些是有事实依据的策展读法，不宣称全球统一分代。
6. **阶段节点**：按年代排列，准确事件标签、型号/品牌、照片或文字回退、概要、变化、来源、完整详情链接。背景节点另用“历史背景/原型/服务”等文字，不挂展品编号。
7. 有依据的比较贴在对应阶段末尾；关联专题与另一阅读线入口在全线末尾。最后说明核查范围与内容缺口。

阶段范围是所选节点的首尾年份，不表示其他路线消失。游戏中掌机与家庭主机并行，电脑中一体机与笔记本并行，普通数字表没有被智能表宣布淘汰。

### 节点结构

桌面产品节点用“年份/事件约90px + 照片约300px + 正文”开放布局；宽度不足时照片与正文合为一列。手机依次为事件年份与身份、型号/品牌、照片与署名、概要、变化、日期解释、来源、详情入口。

背景节点只用年份、身份、标题、说明、变化和来源，占用较小高度，不放产品照片框。与展品相关时可给“另读TPS-L2”等详情链接，但1879受话器、1895服务、1973原型等不计入馆藏。源资料不能提供背景照片时保持文字。

节点`dateLabel`原文必须显示。不得将“批准”“计划供货”“官方列售观察”渲染成统一“上市”。Framework首批出货的内部类别可映射`launch`，文字仍写“2021年7月首批出货（2月25日公布）”。F-91W标1989产品线，不把现行593模块实物当1989首批。

来源与署名分开：前者证明文字事实，后者说明照片作者与许可。阶段来源可置于简短的“阶段依据”折叠区，但节点来源仍紧邻。新六件目前无导入照片，文字框写准确型号、年份与“暂无可发布的实物照片”，不使用品牌渲染图、其他版本照片或虚构剪影。

## 访问、分享与返回

继续使用`/chronicles/?type=phones`等现有地址，新增`type=players`和`type=gaming`。阶段地址示例：`/chronicles/?type=phones#phones-keys`；节点地址保留`#phones-nokia-3310-2000`。不另建平行的时间线系统。

| 操作 | URL与位置行为 |
| --- | --- |
| 从首页进入阶段 | 携带品类与阶段hash；进入对应段落，标题不被固定栏遮住 |
| 切换到另一品类 | 记录当前品类节点/段落；首次访问新线回到起读产品；再次访问同线恢复当前位置。明确选择“从起点读”则重置 |
| 页面滚动 | 不为每个滚动位置添加历史记录；分享链接只取明确定位的阶段或节点 |
| 分享/刷新 | `type`与hash在新会话可恢复；不得要求同一sessionStorage才能到达 |
| 从节点进入详情 | `?from=chronicles&type=phones&node=phones-nokia-3310-2000&stage=phones-keys`；显示返回手机编年史，并保留段落与节点 |
| 从详情返回 | 优先有效URL上下文；同会话恢复原滚动值，跨会话落到节点。直接详情不继承陈旧来源 |
| 馆藏筛选进入详情 | 保留`q/category/decade/sort`与列表位置，详情返回同一筛选；从编年史直接到馆藏可带正式分类，但不伪装成阶段筛选 |
| 旧hash、缺失阶段 | 原29节点保持；只有stage参数时可由节点推导；品类/节点不匹配时显示提示并回到该线，不跳到别的隐藏内容 |
| 浏览器前进后退、⌘/Ctrl点击 | 保留原生链接行为与位置；普通点击可增强，修饰键不拦截 |
| 无JavaScript | 七线静态正文依次展示，品类/阶段为原生锚点；详情和史料可读，品类隐藏与精确滚动记忆只作增强 |

返回上下文只接受本地已知品类/阶段/节点/展品组合，不能接收任意外部返回URL。已有`/timeline/`退路继续转到编年史；其他撤展地址和未知展品保持真实404。
