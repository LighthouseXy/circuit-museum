# 家用、移动与佩戴展品解释性修订 8

本包仅含内容修订；思考档沿用 medium，未更改共享文件或实施代码。

## F-91W（593模块，标准黑色款）

1989年（原F-91W推出年份；具体日未核定）

读者要点：先看持续显示，再用三个按钮切到闹钟和秒表。它让较少而独立的时间任务成为一种完整腕上选择。

### 背景

Casio的腕表年代档案把F-91W的推出放在1989年。它以读时、日历、闹钟和秒表组织日常需求，标准黑色款的树脂外形将显示与按钮集中在腕上。设计师Ryusuke Moriai在原始访谈中回顾，这项设计来自追求小而扁平的目标，也要回应内部电池、石英部件的形状。这里展示的是原F-91W产品线，现行593模块手册帮助解释操作；照片和现行规格并不等于1989制造批次。这样处理年代与实物身份，能够让观众认识长时间存在的产品形态，同时保留不同生产版本需要进一步核对的空间。

来源：B:EA02-C01, B:EA02-C04, B:EA02-C03

### 设计

矩形LCD、边框上的功能标记和三个侧面按钮共同组织操作。读时状态让时间直接可见，进入闹钟、秒表或设置模式后，同一个按钮承担不同动作。设计师的回忆把外壳尺寸与部件安排联系起来，提醒观众薄型外观包含内部布局的约束。树脂表壳与表带形成轻巧的腕戴物，界面则用少数状态表达功能。策展上可以把外形、按钮位置和模式提示同时放大，观察使用者如何从标记判断下一步：小尺寸给佩戴带来便利，也让功能说明必须借助固定符号和操作顺序完成。

来源：B:EA02-C02, B:EA02-C03, B:EA02-C04

### 使用

593模块指南描述了从日常读时进入闹钟、秒表和时间日历设置的顺序。使用者可以选择12或24小时表示，设置每日提醒，或在秒表里开始、暂停与记录分段时间；不同模式中的按键分工并不完全相同。展览可以据此重建一次看时间、定提醒和测量间隔的流程。CROWN作者另回忆自己在新加坡服役时使用F-91W，这提供了一位使用者的具体生活场景，却不足以证明军队普遍配发或全体使用。将操作说明与有限的个人见证并置，可以同时说明产品能做什么，以及我们知道哪些实际使用经历。

来源：B:EA02-C03, B:EA02-C04

### 意义

每天看时间、定提醒和量一段间隔，并不一定需要手机账户或持续网络。F-91W将这些任务留给LCD与三按钮，593模块手册支持读时、闹钟和秒表之间的切换，品牌年代档案则定位原产品线。与Pulsar P1按键唤出红色数字相比，它的日常读时直接可见；与初代Apple Watch的应用、触觉提示及手机配合相比，它选择较少而独立的腕上任务。CROWN设计师访谈解释扁平形态与内部部件的取舍，作者Alvin Wong的服役用表回忆只提供一个具体使用场景，不能扩成军队普遍采用。选择它，是因为基本工具的价值能由按钮和状态持续讲清，不必追求每代增加更多信息。少量键需要复用、日期仍有人工调整边界，简洁并不等于完全不用学习。证据支持操作、形态和个人见证，尚不能证明所有生产批次耐用程度；现行593说明也不能假装成一九八九年实物的全部配置。

来源：B:EA02-C05, B:EA02-C03, C:CH02, C:S38, C:CH03

### 取舍

少量按钮复用多个功能，设置时间或提醒需要辨认当前模式并记住步骤。现行规格中的日历把二月按28日处理，提醒使用者自动显示也有需要人工照看的边界。厂商只标示Water Resistant，展览不会把它改写成潜水深度或极端运动耐久保证；宣传中的电池时长也有使用条件。基本任务集中带来简洁，同时留下看懂标记、调整日期和维护电池的工作。个人使用回忆与编辑设计评价都不构成可靠性统计，观众据此可以讨论取舍，但不能从一个熟悉的外形推断所有批次和所有环境的表现。

来源：B:EA02-C02, B:EA02-C03

## Nokia 3310（2000年原版）

2000年9月1日（发布；原稿计划第四季度供货）

读者要点：在有限数字键上写一条短信，再确认收件人与发送。它让随身文字联系的学习动作与网络条件都清楚可见。

### 背景

Nokia在2000年9月1日公布原版3310，发布稿把供货安排在当年第四季度。它面向GSM 900/1800网络，把通话之外的文字联系放进掌中：聊天仍经由短信通道，收件人不必拥有同样的聊天界面。英国科学博物馆保存的一部带O2 SIM卡的3310，使这款手机有可核对的实物身份。这里的年代对应产品发布，馆藏则记录一部具体设备；二者共同支持型号定位，尚不能确定每个地区的首次购买日。观众可以从它看见短信、号码簿与运营商网络如何形成一套移动联系工具。

来源：B:EA01-N01, B:EA01-N02

### 设计

屏幕下方的Navi键配合数字键和菜单文字完成选择，天线藏入机身，前后外壳可以更换。联系人、短信与小游戏共享这一组实体控制，使用者从屏幕提示辨认当前按键的作用。后盖、电池和SIM卡的安装结构又把外观、能源与身份接入分成可接触的部分。更换外壳改变握在手中的物件，更换电池维持工作，SIM卡联系服务账号；这些动作有各自的对象。策展上可以沿着一次装卡、开机和发消息的过程展示机身，让观众把个性化外表和实际通信条件联系起来，而不只认出熟悉的轮廓。

来源：B:EA01-N01, B:EA01-N03

### 使用

按照原型号用户手册，使用者可以从号码簿选择联系人，拨号通话，或在短信菜单里输入、检查并发送文字。数字键承担多个字母，传统输入需要连续按键，预测输入则按词组织候选；确认和修改仍由屏幕提示与实体键完成。聊天界面把消息排成往返记录，底层仍是短信。这是一条依据手册重建的典型操作，不代表所有人的熟练程度。把输入、选收件人和确认发送分别展示，能够让观众体验文字联系如何被分配到有限的键上，也看见“随身交流”需要经过哪些可学习的动作。

来源：B:EA01-N03, B:EA01-N01

### 意义

声音通话之外，人还需要在不同时刻读到一段短文字，有限数字键便要承担字母输入。原版3310用Navi键与屏幕提示选择，用多次按键或预测输入编写短信，聊天界面再将往返消息组织成记录，底层仍是短信服务。原发布稿与确切型号手册支持这一工作链，英国馆藏提供一件实际设备的身份。与8000X以实体数字键和红色显示确认通话号码相比，3310把文字处理带入联系任务；与初代iPhone的软件键盘相比，它的输入空间固定，使用者在按键、候选和确认之间配合。选择它，是为了把普通短信手机当作有完整结构的工具，而不是只当后代前史。可更换外壳、电池和SIM各有目的，个性化外表不替代网络条件。原移动交互实验还提示步行情境与实验室发现的问题不同，体验必须放回现场；“摔不坏”传说没有替代原手册的维护条件。

来源：B:EA01-N02, B:EA01-N01, C:S16, C:TXM13A, C:TXM13B, C:S25, C:S33, C:TXL01

### 取舍

通话和短信依赖兼容网络、SIM卡以及运营商提供的服务，说明书也区分设备功能与网络条件。小屏和数字键要求输入、修改、选择之间不断配合，预测文字并不消除确认工作。原始移动交互研究把3310纳入实验，发现步行街与实验室模拟情境识别的问题并不一致，提醒我们把操作放回使用环境。这个范围有限的研究不能推出所有用户体验。原手册还要求避免潮湿与跌落，因此展览不采用“摔不坏”的网络传说；设备维护条件与通信操作一样，是理解这部手机的一部分。

来源：B:EA01-N03, B:EA01-N04

## Ericofon

1956年量产（1954试产；1953展示不等同销售）

读者要点：翻看底部拨盘，再看放回桌面怎样接到断路按钮。它让外壳姿态成为通信界面的一部分。

### 背景

Ericofon来自将固定电话整合为一体的长期设计过程。原厂历史分别记录一九五四年试制和一九五六年开始的Karlskrona生产，本条以量产为年代锚；MoMA所藏实物的一九四九至一九五九年范围承担另一种登记作用。拨盘和听筒不再分别留在机座与手中，使用者拿起的是同一外壳。电话仍要接到相应线路，通信位置并没有因为外观整合就自动跟人移动。早期两半壳体与一九五八年的单件注塑改型分别处理，形态看似相近，材料制造与部件配置仍各有版本。

来源：HC150-S019, HC150-S020

### 设计

原厂说明其概念是让桌面电话站在拨盘上，并在拨盘中央设置控制断路的按钮。听筒和拨号装置因而进入同一个外壳，底部不再只是摆放的支点，也是操作界面的一部分。厂商历史记录了模型试作和人体使用试验，以及在投产时采用ABS热塑性材料的选择；MoMA实物记录又提供材料与设计者信息作为另一种核对。展览解读的重点可以放在形态如何对应动作：弯曲外壳让握持部、听筒位置和桌面支撑发生联系。这里不把形态的醒目等同于每个人都感到舒适，也不将原厂所说的耐冲击和颜色优势转换成未经量测的耐用排名。

来源：HC150-S019, HC150-S020

### 使用

一次联系可以从拿起外壳、翻看底面找到拨盘、逐位拨号，再将听说部位安排到耳与口之间展开。号码输入和通话姿态使用同一件物体，却不是同一方向，使用者需要转动与重新握持。结束时将设备放回桌面，底部中央按钮把姿态与断路控制相接；桌面于是既是支撑位置，也参与结束动作。原厂曾描述将铃声机构放入独立墙盒的概念，所以铃声来源不能只从机身外观推定，也不能假定各地区配置一致。人在使用时需辨认自己的线路、铃与壳体阶段，原设计动作可以据档案理解，接线和今天的网络适配仍需对应实机资料。

来源：HC150-S019, HC150-S020

### 意义

桌面电话通常把拨号留在机座，把说听留在拿起的听筒，两个位置要求一串转移。Ericofon把听筒与底部拨盘合进同一外壳，中央断路按钮又让放置姿态参与线路控制，原厂历史明确说明这些设计关系。与Model 500外围字码、桌面拨盘和独立听筒相比，人需要拿起并翻看底部，再拨号和重新放下；与8000X的正面键盘及手持通话相比，两件虽然都可握持，Ericofon仍连到固定线路，便携网络不能由一体外形推出来。选择它，是因为控制界面改变位置时，最平常的拿、看、转动与放下也跟着重排。MoMA材料与设计者记录帮助确认实物，原厂人体试验叙述提供设计过程，二者都没有证明每个人更舒适。不同铃声和壳体阶段仍需对应，证据能解释已核一体结构的动作，不应把醒目造型或品牌赞语直接写成社会效果。

来源：HC150-S019, HC150-S020, HC150-S017, HC150-S018, C:S16, C:TXM13A, C:TXM13B, C:S25

### 取舍

一体式结构减少了分开的机座与听筒，却要求拿起后辨认底面并改变握持。拨盘的位置不保证每个人都更方便，原厂试验与材质优势描述也没有给出可通用于所有人的测量结论。早期两半壳、后来的改型及不同铃声配置需要逐型核对，配色本身不新增工作路线。固定线路继续限制使用位置，塑料、触点和电线状态则关系到具体存世机器，未做运行检查就不能承诺可靠性。量产起年与设计年代范围也不能替代出口市场首售；这些未知不改变已核布局，却限定能够讨论的产品版本和动作。

来源：HC150-S019, HC150-S020

## ER-4

1955-12-10（日本发售）

读者要点：看外锅水怎样从操作材料变成结束控制的媒介。它展示米食家务中的自动化，可以由容器、材料和温控共同实现。

### 背景

ER-4在日本于一九五五年十二月十日发售，国立科学博物馆产业技术史数据库将其列为量产品，条目由电机行业协会调查填报，所在地记录为东芝未来科学馆。厂商技术史又将其置于自动炊饭器发展中。厨房以米饭为重复任务时，需要处理的不只是把热送到食物，还包括米与水怎样到达合适过程并停止供热。ER-4用间接加热与外锅水参与判断，器具的任务因此可从材料、锅体和控制配合来理解。数据库登记有机构与产业填报背景，型号和日期的核定作用不等于独立家庭成效研究。

来源：HC150-S005, HC150-S006

### 设计

三重锅结构把盛米的部分与外锅水的物理过程关联起来。预定外锅水在加热过程中蒸发，温控器在相应条件切断，水因而既是人要准备的材料，也是机器回应的控制媒介。它不是直接读取任意食材成熟度，而是先组织一个能到达明确状态的过程。内外容器、供热与温控不能单独拆开评价：只有准备关系成立，结束判断才有具体对象。与直接让内锅接触加热板的结构相比，间接路径使外锅水留在工作链中。所核历史资料可说明这种关系，未给出全部电路与温控数值，不能用后来保温菜单或现代传感方式填满早期配置。

来源：HC150-S005, HC150-S006

### 使用

人先准备米和水，并安排内外锅各自承担的材料，使外锅水能够参与预定的蒸发过程。电热提供持续能量，水的变化与温控将其中一段结束判断交给装置；人不需要把每一个结束动作都留在手动热源上，材料准备却不能因此略过。完成后还要开盖、盛取、处理残留并清理接触食物的容器，为下一次重建相同工作关系。这个流程说明自动结束发生在何处，而不是给出存世旧机操作处方。现有来源没有足够逐步原说明书，米量、计量杯刻度、开关和精确装填顺序仍未核，不能把理解结构当成可直接运行的完整步骤。

来源：HC150-S005, HC150-S006

### 意义

米饭烹制要管理供热，也要判断何时结束，操作者原本需要持续关注锅中的过程。ER-4将预定外锅水的蒸发与温控断电接起来，三重锅结构让材料本身成为控制媒介，逐型产业档案与原厂技术史支持这一关系及日本发售节点。与次年EC-36内锅直接接触加热板、恒温器和重盖的路径相比，两件围绕同一米食任务，热与控制信号却安排不同；与TM5的食谱芯片和触屏步骤引导相比，ER-4自动承接的是一段热过程的结束，而非整套配方内容。选择它，是因为家庭自动化可以从水、容器与温控之间的物理配合看懂，并不一定先有复杂软件。人仍准备米与内外锅的水，盛取和清理也保留，外锅水不能当无关附件。档案可证明量产品与结构，不足以证明所有家庭省下多少时间；不同环境、米量与水状态如何影响结果，需要原版操作或实测进一步限定。

来源：HC150-S005, HC150-S006, HC150-S007, HC150-S008, HC150-S061, HC150-S062

### 取舍

外锅水参与控制，准备变化就可能改变过程，间接加热的结果也需要与米、分量和环境条件一起理解。现有资料未提供可对比的食物结果与温控精度实测，自动断电不等于每一锅都达到同一种口感。两份主要来源分别承担逐型登记与技术回顾，均与产业或品牌记录有关，不能当成两次独立家庭效果测量。日本发售节点不替代其他市场日期，后来的保温型也有自己的结构。量产可以确认它已成为产品，家庭普及、购买经验与劳动时间仍是需要另外证据的问题；这些边界保留了自动结束的具体意义，不将整顿饭都交给机器。

来源：HC150-S005, HC150-S006
