## 相似感来自哪里

| 方面 | 具体对照 | 判断 |
| --- | --- | --- |
| 构图 | 两站都以左侧两行大标题、说明、双按钮、数量提示，配右侧大展示区，再接三列栏目 | 最强相似来源；换产品照片仍保留同一首页骨架 |
| 配色 | 对照站 `#f7f5f0 / #2d5a3d`；博物馆 `#f7f6f2 / #365a4b` | 数值不同，感知非常接近；都由暖白底、深绿强调、灰色细线构成 |
| 标记与导航 | 左侧圆形标记带小点，文字品牌，横排导航，当前项细下划线 | 圆形标记与整体摆位进一步加强同族感 |
| 字体 | 对照站标题用Noto Serif SC，博物馆用系统无衬线；两站仍有英文小标签、数字/年份和细线 | 字体并未相同；微小展签与模块标题的节奏却接近 |
| 卡片 | 对照站圆角阴影参数卡，博物馆直角白色图片展台；均反复三列并用小标签—标题—说明排序 | 局部样式不同，页面阅读节奏相近 |
| 信息结构 | 对照站是类别/最新样本/规格；博物馆是精选/主题路径/影像 | 内容不同，但都按门户首页的同类分段组织；缺少由藏品叙事决定的独立布局 |

这是本轮设计与审阅没有及时识别出的同质化问题。此前只检查“产品照片是否足够大、是否无霓虹与纹理”，没有把整页构图和既有作品放在一起判断；现有视觉验收结论因此收回。下一版需要改变页面组织和阅读路径，而非仅换色、换标志或改字体。

## 下一步设计边界

独立方向采用“按品类翻阅的产品史图录”：以五条发展脉络作为首页主内容，进入即看产品及其变化；取消左右营销首屏、双CTA与数字统计带、圆点环形标记和连续三列门户模块。保留中性背景与清楚字体，以纵向年表、较大实物照片和紧邻的变化说明组织页面。具体方案另见 `chronicles-design.md`。事实核查与40件馆藏约束继续有效；新视觉和“产品编年史”均须实现后重新验收。
