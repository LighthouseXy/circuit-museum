## 1. 项目定位与工作范围

**赛博电子博物馆：看见电路如何改变日常。** 以中文为主，通过真实产品照片、简洁的历史叙述与原发布方影像，介绍电子产品的形态、交互与生活方式。主标题使用 Circuit Museum，中文名用于副标题与页面说明。

首展主题：**从信号到随身世界**。以 1904 年电子管、1920 年代广播与 1947 年晶体管作为序厅背景，展示 1924—2022 年的 40 件实物产品。2020 年代选 Steam Deck LCD（2022）；截至本次策展日期，它是已核实的现代案例，不称为“最新产品”。从早期电子技术走到当代产品，采用精选叙事，不宣称穷尽电子史，也不暗示空缺年代没有创新。

本轮检查时 `/Users/xyu/Program` 是其他项目的父目录；开始时 `circuit-museum` 尚不存在，随后由代码线程建立。所有本项目产出位于 `/Users/xyu/Program/circuit-museum`，本线程只写其中 `docs`，未扫描或修改其他项目。未发现适用上级 AGENTS.md 或已有项目设计文档。本线程负责策展、事实与媒体来源、体验设计；代码线程负责实现、测试、素材落盘和实施文档。无需另建后端、收费 API、账号或 CMS；不购买素材、不公开部署。

## 3. 信息架构与页面

主导航只有“馆藏”“时间线”“关于本展”；品牌回首页。建议路由如下，实现可因已有技术约束等价调整，但须保留独立、可直接访问的详情地址。

| 首页 | `/` | 主展标题、真实展品主图、简短导言、三件首页精选、三条主题路径、影像入口 |
| 馆藏 | `/exhibits` | 全部 40 件、搜索、类别和年代筛选、排序、结果数、清除筛选 |

## 4. 浏览和搜索规则

馆藏默认按年份升序；同年按名称排序。搜索覆盖 `name`、`brand`、`aliases`、`tags`、`summary`；忽略大小写、首尾空格，并把连字符/空格差异标准化。无需拼音或语义搜索。例：`walkman`、`随身听`、`TPS L2` 均应命中 TPS-L2；`苹果` 应命中九件 Apple 展品。

类别、年代均单选，均有“全部”，两者和搜索按 AND 组合。显示非零馆藏年代：1920s、1930s、1950s、1960s、1970s、1980s、1990s、2000s、2010s、2020s。背景节点不计入馆藏数量。排序提供“年代由早到晚”“年代由晚到早”，无需复杂推荐。

URL 保存 `q`、`category`、`decade`、`sort`，后退及分享可恢复状态。无结果显示“没有找到符合这些条件的展品”，保留输入和筛选，并提供“清除全部条件”；不得把网络错误写成无结果。搜索结果数用温和的状态播报，避免每次按键抢焦点。

返回馆藏保留查询参数与滚动位置。详情页“继续探索”用策展指定关联，每件 2 件；不是购物推荐。未知 slug 有明确的未找到页面与回馆藏入口。

## 5. 时间线与详情阅读

时间线使用纵向时间轴，桌面可两列（左为年代导航，右为内容），手机单列。不使用必须拖动的横向画布。1904、1922、1947 明确标“历史背景”，没有展品编号或伪造实物图；1924 起显示真实产品节点。节点距离不伪装成精确年份比例。顶端说明“沿早期背景与四十件精选，阅读至 2020 年代”。

详情页顺序：返回馆藏 → 年份/品牌/分类 → 产品名和一句展签 → 主图与完整署名 → 时代背景 → 设计观察 → 关键事实 → 为什么入选（标“策展解读”）→ 拆解与内部观察（仅3件有补充时）→ 影像（仅有登记条目时）→ 两件关联展品 → 史料来源。

首屏图文并列，手机主图在名称后、正文前。正文宽度 38—44 个中文字；每段 2—4 句。每个事实段或事实表附紧邻的可点击来源标签，不只在页底笼统写“资料来自网络”。媒体署名不能折叠到找不到的位置。主图可点击“查看大图”，允许简单新页/原文件链接；不强制做复杂图库或 3D。

## 6. 视觉与响应式

方向：以产品为主的现代藏品图录。暖白背景 `#F7F6F2`、白色图片展台 `#FFFFFF`、深灰正文 `#202623`、次级字 `#606963`、细分隔线 `#D9DDD6`、克制的深绿链接 `#365A4B`。颜色只辅助导航，不改变产品原色。优先大幅真实照片、独特细节和历史意义。禁止霓虹、扫描线、电路纹理、装饰网格与巨型标题抢占注意力；不强制深色模式。

中文正文用系统无衬线字体，标题可同字体加粗；英文字标和年份用系统等宽字体。无需外部字体请求。桌面内容最大宽度约 1200px，留白 32—64px，手机 20px。卡片不是满屏小方块：大图、年份、名称、一句展签，避免塞满规格标签。

建议断点：小于 640px 一列；640—1023px 两列；1024px 起三列。图片使用 `contain` 保留机器轮廓，统一浅色展台背景，禁止为填满卡片裁掉屏幕、按键或端口。Steam Deck 横向照片可增加上下留白。可仅做 120—180ms 的悬停/焦点过渡；支持减少动态效果，无自动轮播、背景音乐、开屏动画。

键盘可遍历导航、筛选与卡片；明显焦点环；搜索有可见标签；按钮触控区域至少 44×44px。正常文字对比度至少 4.5:1。320px 宽及 200% 缩放下无正文横向溢出。主图片提供描述性 alt，装饰线条不读出。视频入口有文本摘要，即使第三方不可访问仍能理解其内容。

建议将内容维护为一个本地结构化集合，无需数据库。以下字段定义与 `curatorial-catalog.md`、`media-register.md` 一一对应；不要求使用特定编程语言。

| 字段 | 类型/规则 | 说明 |
| --- | --- | --- |
| id / slug | 唯一字符串 | slug 使用第 2 节固定值 |
| name / brand | 字符串 | 明确型号、代际；品牌不是制造地点 |
| year | 整数 | 用于排序，不由照片拍摄时间推导 |
| dateLabel / dateKind? / market? | 字符串；后两者可选 | 区分发布、上市/发售、首批订购；仅资料足够时精确到日 |
| category | 八选一 | 第 2 节八类枚举 |
| aliases / tags | 字符串数组 | 中英文检索词，3—6 个即可 |
| summary | 1 句 | 卡片展签，不堆叠“全球第一” |

Source：`id, title, publisher, url, supports, checkedOn, accessNote`。Image：`id, exhibitSlug, title, sourcePage, originalUrl/localPath, creator, credit, license, licenseUrl, changes, alt, checkedOn, status`。Video：`id, exhibitSlug, publisher, title, landingUrl, embedUrl?, rightsMode, language?, duration?, summary, checkedOn, playbackStatus`。未知时填空并隐藏，不编造时长、字幕或视频 ID。

- 五个影像条目 V01—V05 应成为对应详情的可用入口；首页可选前三个，有发布方、摘要和显式站外提示；外链是本次已确定的可交付方式。本轮采用外链即可，无需嵌入。
- 搜索 `随身听` 命中 TPS-L2；`苹果` 命中 9 件；分类 `audio` 为 6 件；`gaming` 为 8 件；`2020s` 为 1 件；`gaming + 1980s` 为 Famicom 与 Game Boy；任意不可能条件出现可清除的空状态。

## 9. 实施顺序与后续路线

同一个首版内依次完成：①导入 40 件正文和媒体登记，下载并检查主图；②实现页面骨架与统一展签；③接通搜索、分类、时间线与关联；④接入五条影像外链及选择性拆解；⑤完成响应式、无障碍、来源和断链检查。不得把第①或第④整体排到下一版。

首版之后才考虑：补充更多中国品牌和地区、扩充家用电子设备及未覆盖的时期；展品对照页；更深的专题文章；确有新增内容需求后再考虑编辑后台。首版不做账户、收藏同步、评论、商城、AI 导览、WebGL 展厅、全历史巨量数据。
